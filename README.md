# SSL 一键申请

基于 `acme.sh` 的菜单式证书管理工具，支持域名、公网 IPv4 / IPv6、自动续期和远程 OpenWrt 部署。

## 一键运行

在 Ubuntu / Debian / CentOS / RHEL / Rocky Linux / AlmaLinux / Fedora 上，以 **root** 执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/slobys/SSL-Renewal/main/acme.sh)
```

再次执行即可更新脚本，保留已有证书和设备配置。

## 功能与菜单

| 主菜单 | 用途 |
| --- | --- |
| 1）域名证书 | 在本机为域名申请证书 |
| 2）本机固定 IP 证书 | 云服务器常用；自动识别或手动输入 IP，推荐验证方式 |
| 3）本机动态 IP 证书 | 在同一子菜单开通、查看、立即检查或停用 IP 变化检测 |
| 4）远程 IP 证书 | 云服务器为 OpenWrt 软路由申请并回传证书 |
| 5）更新 / 重新部署脚本 | 确认后更新，保留证书和配置 |
| 6）退出 | 结束运行 |

**云服务器自己用选 2；云服务器替家中软路由申请选 4，无需先开通 3。** 原第 3、4 项已合并，原远程入口从 5 移至 4；已有配置和自动任务无需迁移。

第 3 项只跟踪运行脚本的本机公网出口，每 5 分钟检测变化并自动重签；使用固定证书路径，可配置服务重载。IP 未变化时仍需正常到期续签。停用仅移除 IP 变化检测，保留证书和 acme.sh 原有续期记录。

### 云服务器给家里 OpenWrt 申请

进入 **4 → 添加远程设备 → 配置远端固定 / 动态公网 IP**。填写 SSH 地址、邮箱、证书路径和重载命令，后续在此菜单查看状态、更新证书或删除设备；各子菜单按 `0` 返回主菜单。

管理连接需要 **SSH 密钥登录**；家庭动态 IP 场景建议填写 ZeroTier 等稳定管理地址。OpenWrt 无需安装 ACME 插件，但家庭公网 **TCP 80 必须可达**，上级光猫的端口映射需自行设置。

验证流量经家庭公网 IP、临时 SSH 隧道到达云服务器；签发成功后，证书和私钥通过 SSH 部署回设备。

> 远程模式可能启用 Dropbear `GatewayPorts` 并重启 SSH，验证期间会临时修改防火墙规则，请先备份配置。云服务器会保存私钥；不要为了验证而开放整个 LuCI 管理界面。

## 验证方式怎么选

| 方式 | 公网端口 | 适用情况 |
| --- | --- | --- |
| HTTP-01 临时服务 | TCP 80 | 80 空闲，优先选择 |
| HTTP-01 网站目录 | TCP 80 | 已有 Nginx / Apache，填写实际网站根目录 |
| TLS-ALPN-01 临时服务 | TCP 443 | 80 不可用，443 可被临时独占 |

本机菜单会检测端口并推荐，不会自动停止网站。**续期时也要满足验证条件**；远程 OpenWrt 模式目前仅使用 HTTP-01。

## 证书保存位置

| 模式 | 证书 / 私钥 |
| --- | --- |
| 本机域名 / 固定 IP | `/root/<域名或IP>.crt`、`/root/<域名或IP>.key` |
| 本机动态 IPv4 | `/root/dynamic-ip-v4.crt`、`/root/dynamic-ip-v4.key` |
| 本机动态 IPv6 | `/root/dynamic-ip-v6.crt`、`/root/dynamic-ip-v6.key` |
| 远程 OpenWrt 默认 | `/etc/uhttpd.crt`、`/etc/uhttpd.key`，可自定义 |

固定 IPv6 文件名中的 `:` 替换为 `_`。实际服务需配置为读取对应文件；动态和远程模式应设置正确的重载命令。

## 必要提醒

- IP 证书使用 Let's Encrypt `shortlived`，有效期 **160 小时**，务必保持自动续期正常，避免频繁强制重签。
- 仅支持可验证控制权的公网 IP。**检测到出口 IP、端口空闲，不等于公网可达**；请检查代理影响、CGNAT、运营商限制、安全组和 NAT。
- 动态重签不是 DDNS：本项目不自动更新 DNS，也不会把新 IP 通知远程客户端。仅含 IP 的证书不能用于验证域名访问。

已完成离线交互测试，真实 CA 签发及 OpenWrt 链路仍需实机验证。测试命令：`python3 tests/test_smart_menu.py`。
